## 👤 Sobre mim

Sou estudante do curso de **Banco de Dados** na **FATEC Prof. Jessen Vidal**.

Atualmente, estou desenvolvendo habilidades tanto em Desenvolvimento Full Stack quanto em Análise de Dados. Gosto de explorar tecnologia com curiosidade e entender como cada parte contribui para soluções completas — desde o design de dados e a lógica no backend até a construção de interfaces no frontend e a análise que transforma informação em valor.

Sou uma pessoa curiosa, organizada e comunicativa. Acredito que a tecnologia conecta lógica e impacto real. Busco ambientes que valorizem inovação e aprendizado contínuo para desenvolver soluções que sejam robustas, funcionais e bem arquitetadas.

## 🧠 Principais Conhecimentos

- 💻 **Desenvolvimento**
  - Front-end: `Vue.js`, `TypeScript`, `JavaFX`
  - Back-end: `Java`, `Spring Boot`, APIs REST
  - Banco de Dados: `MySQL`, `PostgreSQL`, `Oracle` (modelagem e persistência SQL/NoSQL)
  - Integração: `Axios`, consumo e padronização de endpoints REST
- 📊 **Análise de Dados**: visualização e interpretação estratégica de dados
- 🔧 **Infraestrutura e Workflow**: `Docker`, `Git`/`GitHub`, versionamento
- 📋 **Metodologia Ágil**: Scrum e Kanban, participação como Scrum Master e como Dev Team
